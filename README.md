# S-OIL 수급 의사결정 연구

시장·공시 자료에서 확인할 과제를 정하고, 생산계획에 필요한 원료를 언제 얼마나 확보할지 가상 조달 대안으로 비교한 연구입니다. S-OIL의 공식 자료나 내부 운영시스템이 아닙니다.

## 핵심 질문

**기존 조달 기반을 전제로 추가 물량을 검토할 때, 필요한 시점·물량·실행 조건을 충족하면서 총조달비를 비교하려면 어떤 정보를 연결해야 하는가?**

단순히 저렴한 원료를 고르거나 재고를 많이 확보하는 문제가 아닙니다. 같은 구매량과 기말재고에서 사용 가능일, 일별 투입량, 저장 여유, 최소 구매량과 공급 확약을 함께 확인합니다. 시장 상황을 특정 카고의 지연·가격으로 자동 변환하지 않습니다.

## 이번에 확인한 결과

모든 운영값과 가격이 가상인 Cowork 사례에서 하루 지연에는 필요한 기간만 보완하는 C80, 이틀 지연에는 전량 조기 확보 B가 선택됐습니다. 저장 한도를 낮추면 B를 제외하고 C160을 선택합니다. B의 소량 구매를 허용하면 D80이 C80을 대체합니다. 따라서 결론은 가격만 아니라 물량·일정·견적 조건에 의존합니다.

Cowork 대표 사례 10개와 252개 조건 조합을 재실행했습니다. 같은 252개 조합을 별도 폐쇄형 계산식으로 교차검사하고 2개 비용 동률 경계도 확인했습니다. 두 검사는 같은 가상 조건을 검토한 것이지 서로 다른 504개 시장 관측치가 아닙니다. [검증 요약](integration/2026-10-14/validation-summary.json)

```bash
python cowork/2026-10-14-supply-decision/verify_design.py --check
python cowork/2026-10-14-supply-decision/verify_design.py
python integration/2026-10-14/independent_review.py
```

Python 표준 라이브러리만 사용합니다. 자동 구매·용선·운전 변경 기능은 없습니다.

## 범위와 한계

공식 수급 업무에는 공장최적화, 원료 구매, 용선·통관, 수급·재고·판구매 관리가 포함됩니다. 이 연구는 그 전체를 구현한 것이 아니라 **생산계획을 주어진 조건으로 둔 발주 전 추가 조달 비교**를 구현했습니다. 공장 가동량·운전모드·실제 원유별 수율·제품 판매수익은 계산하지 않았습니다.

샤힌의 정유·석유화학 연계와 원료 유연성은 회사 이해의 배경입니다. 샤힌의 실제 원료 배분이나 정상 가동 효과를 입증하지 않습니다. 추가 조달 500kbbl와 7일 기간은 학습용 설정이며 회사 카고 크기·계획 주기가 아닙니다. 가상 비용 차이를 회사 절감액으로 사용하지 않습니다.

1Q26·2Q26 IR의 Cowork 텍스트 확인 기록은 유지하지만, 이번 실행에서도 PDF 페이지 이미지 대조는 완료하지 못했습니다. 83% 등 도표·설계 수치를 현재 실적 또는 자기소개서의 필수 수치로 채택하지 않았습니다.
