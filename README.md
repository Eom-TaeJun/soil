# S-OIL 수급 의사결정 연구

공개자료로 산업과 직무를 이해하고, 경제성과 실행 가능성을 함께 검토하는 작업물입니다. S-OIL의 공식 자료나 내부 운영시스템이 아닙니다.

## 먼저 정한 문제

**원료의 가격상 이점이 운임, 도착 시점, 재고와 출하 제약 때문에 사라질 때, 무엇을 확인하고 어떤 계획을 다시 비교해야 하는가?**

기술을 먼저 만들고 직무에 연결하지 않습니다. 정유산업 → S-OIL의 문제와 실제 대응 → 수급의 업무·협업 → 보여줄 판단 역량 → 이를 뒷받침하는 사례와 검증 순서로 진행합니다.

핵심 역량은 분석 도구 자체가 아니라 **시장 정보와 현장 조건을 같은 기준으로 정리하고, 실행할 수 없는 대안을 걸러낸 뒤 비교 근거를 설명하는 능력**입니다.

## 현재 범위 — 2026-10-14

산업·회사·직무 분석, 세 가지 사례 설계, 가상 입고·재고 산술 예제와 테스트를 다룹니다. 원료 전환과 샤힌 연계 출하 사례는 설계 단계입니다. 실제 수율·계약조건·재고·탱크용량·부서별 결재권한은 확보하지 않았습니다.

가상 예제는 회사의 최적 구매안이나 손익을 산출하지 않습니다. 값은 전부 학습용 가정이며, 실제 원유가격이나 S-OIL 운영값이 아닙니다. 근거 문서와 가상 입력은 서로 대체할 수 없습니다.

```bash
python examples/arrival_inventory.py
python examples/arrival_inventory.py --test
```

Python 표준 라이브러리만 사용합니다. 외부 API, API 키, 유료 데이터, 자동매매·구매 기능은 없습니다.

## 자료의 상태

사용자가 제공한 49개 항목의 링크 모음을 출발점으로 핵심 자료를 재확인했습니다. 49개 원문을 모두 다시 열거나 모든 PDF를 검토한 것은 아닙니다. 특히 2026년 2분기 IR·2025 ESG PDF, 2026년 10월 IEA/EIA 원문은 이번 접근에서 확보하지 못한 항목이 있어 수치를 확정하지 않았습니다. 원문 확인, 검색 발췌, 기존 조사기록, 미확인을 [출처 등록부](sources/registry.md)에서 구별합니다.

## 후속 작업 원칙

[AGENTS.md](AGENTS.md)를 먼저 읽습니다. GS칼텍스의 회사명·조직명·운전 조건을 S-OIL로 바꾸어 복제하지 않습니다. 공개 저장소에 미제출 자기소개서, 개인정보, 비공개 경험 원문을 넣지 않습니다.
