# S-OIL 수급 의사결정 연구

공개자료로 산업과 직무를 이해하고, 경제성과 실행 가능성을 함께 검토하는 작업물입니다. S-OIL의 공식 자료나 내부 운영시스템이 아닙니다.

## 먼저 정한 메시지

**시장 변화를 원료의 실제 사용 가능 시점과 공장·판매 조건에 연결해, 실행 가능한 수급 대안을 숫자로 설명하고 협업에 필요한 확인사항을 구조화한다.**

산업·회사 → 실제 수급 업무와 협업 → 보여줄 역량 → 필요한 증거 → 구현 순서를 지킵니다. 결과를 미리 정해놓고 가정을 맞추지 않습니다.

이 프로젝트는 1500자 지원서 중 사용자가 직접 작성할 포스코 경험 약 1000자를 대체하지 않습니다. 나머지 약 500자에서 그 판단 방식을 S-OIL 수급에 적용해 본 근거를 제공합니다. 제출용 자기소개서 본문이나 개인 경험 원문은 공개하지 않습니다.

## 현재 구현 — 2026-10-14 2차 업데이트

주 질문은 가격이 유리한 원료도 필요한 때 쓸 수 없다면 어떤 수급안을 다시 비교할 것인가입니다. 새 P1은 도착·품질/통관 해제·사용 가능 재고·도착원가를 연결합니다. 3개 가상 대안, 7개 시나리오, 14개 테스트를 실행했습니다.

공개 수치는 EIA가 발표한 2026년 9월 Brent 월평균을 과거 공통 기준으로만 사용합니다. 원료 차등·운임·보험·일정·재고·적합성은 모두 가상입니다. 실제 S-OIL 구매가격·원유 수율·공장 LP·계약·최적 계획이 아닙니다. 기준가격 자체는 동일 물량 대안의 순위를 바꾸지 않습니다.

```bash
python examples/readiness_case.py
python examples/readiness_case.py --test
```

기존 전부 가상인 산술 예제는 그대로 유지합니다.

```bash
python examples/arrival_inventory.py
python examples/arrival_inventory.py --test
```

Python 표준 라이브러리만 사용합니다. API 키, 유료 데이터, 자동 구매·용선·운전 변경 기능은 없습니다.

## 완료와 미완료

완료: 메시지·증거 배치, 공식 업무와 최신 시장 사건의 연결, 공개/가정 자료 분리, 사용 가능 재고를 검사하는 P1 확장과 14개 신규 테스트.

설계만 완료: 내부 유분 외부 판매 대 내부 투입 기회비용(P2), 샤힌 생산 준비 대 고객 인수·출하 조건(P3). 실제 내부자료, 현업 적용, 회사 절감액, 시간·오류 개선율은 검증하지 않았습니다.

2026년 2분기 IR·2025 ESG PDF 및 10월 IEA/EIA 보고서 전체는 이번에도 충분히 직접 확보하지 못했습니다. EIA 공식 보도자료와 IEA 공식 발표 등 검색 도구의 수록 본문을 확인한 범위는 별도로 표시했습니다. 49개 원문을 모두 검토했다고 주장하지 않습니다.
