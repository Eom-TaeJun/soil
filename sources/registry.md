# 출처 등록부

기준일: 2026-10-14. 출발점은 사용자가 제공한 「S-OIL 수급 직무·산업·회사 원문 링크 모음」의 49개 항목이다. R번호는 해당 항목 번호를 유지한다. 이 파일의 존재가 모든 링크를 재검증했다는 뜻은 아니다.

‘본문 확인’은 이번 실행에서 읽은 범위, ‘검색 발췌’는 검색 결과에서만 확인한 범위, ‘기존 기록’은 사용자가 제공한 조사기록에 있는 범위를 뜻한다. 확인 수준과 내용의 성격은 별개다. 공식 본문을 읽어도 미래 계획은 실현 성과가 아니다.

## 앞으로 기록할 필드

원문 게시일, 실제 사건일·수치 기준기간, 확인일, 발췌 위치, 자료의 주장, 채택한 해석, 미확인과 갱신 조건을 분리한다. 외부 자료의 전체 본문을 저장하는 대신 필요한 짧은 인용과 원문 링크를 남긴다. 사실을 검토한 기록과 가상의 수치 시나리오를 하나의 실측 데이터셋으로 섞지 않는다.
