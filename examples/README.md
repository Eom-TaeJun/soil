# 입고 시점과 재고를 반영한 가상 비교

**모든 가격·물량·일정·저장 한도는 학습용으로 만든 값이다. S-OIL 데이터나 현재 원유 시세가 아니다.**

## 실행

Python 3.10 이상, 표준 라이브러리만 사용한다.

```bash
python examples/arrival_inventory.py
python examples/arrival_inventory.py --test
```

첫 명령은 세 가지 시나리오의 후보별 일별 수지와 비용, 제약 위반을 JSON으로 출력한다. 둘째 명령은 10개 단위 테스트를 실행한다.

## 질문

도착원가가 더 낮은 대안이 입고 시점·최소재고·저장용량을 만족하지 못해도 더 좋은 계획인가?

비교는 계약 확정 전 후보 선택을 단순화한 것이다. 이미 확정된 계약을 취소 비용 없이 바꿀 수 있다는 뜻이 아니다. 후보 물량의 구매 가능성, 동일한 품질·수율, 선박·하역·통관 여건은 가정이며 실제 적용 시 따로 확인해야 한다.

## 공통 입력

7일 동안 매일 80kbbl을 사용한다. 기초재고는 240kbbl, 총구매량은 500kbbl, 기말재고는 180kbbl이다. 일말 최소재고 80kbbl, 저장용량 600kbbl을 하드 제약으로 둔다. 입고는 해당일 사용 전에 이뤄진다.

kbbl은 천 배럴, 단가는 USD/bbl, 계산된 비용은 kUSD다. 500kbbl × 72USD/bbl = 36,000kUSD = 3,600만 달러다. 이 금액은 가상 비교용이며 실제 회사 지출이 아니다.

| 후보 | 구성 | 기본 도착일 | 기본 도착원가 |
|---|---|---|---|
| A | 500kbbl 단일 물량 | 3일째 | 72USD/bbl |
| B | 500kbbl 대체 물량 | 3일째 | 75USD/bbl |
| C | 160kbbl 브리지 + 340kbbl 후속 물량 | 3일째 + 5일째 | 각각 85, 72USD/bbl |

## 계산

일말 계획재고 = 전일 재고 + 당일 입고 − 당일 계획 사용량.

입고 직후 재고가 용량을 넘는지, 일말 계획재고가 하한을 밑도는지 모두 검사한다. 이미 불가능해진 계획에서 나타나는 음수는 계획의 부족량을 드러내는 산술 결과이지 실제 재고가 음수가 될 수 있다는 뜻이 아니다. 실제 생산을 음수 재고로 진행하거나 자동으로 사용량을 줄이지 않는다.

총비용 = 각 물량 × (원료 가격 + 운임)의 합. 품질·수율, 세금, 금융비용, 보험, 체선료, 계약 취소비용 등은 구현하지 않았다. 실제 도착원가에는 상황에 따라 이 항목들의 추가 확인이 필요하다.

## 실행 결과

금액 단위: kUSD. 세 후보 중 조건을 만족하는 최저비용 후보를 표시한다. 가능한 모든 계획의 최적해가 아니다.

| 시나리오 | A 비용 / 가능 여부 | B 비용 / 가능 여부 | C 비용 / 가능 여부 | 제한된 후보 중 선택 |
|---|---|---|---|---|
| 기본 | 36,000 / 가능 | 37,500 / 가능 | 38,080 / 가능 | A |
| A 입고가 3일째에서 5일째로 지연 | 36,000 / 불가능 | 37,500 / 가능 | 38,080 / 가능 | B |
| A와 C 후속 물량의 운임이 4USD/bbl 상승 | 38,000 / 가능 | 37,500 / 가능 | 39,440 / 가능 | B |

지연된 A는 총량과 기말재고가 맞지만 3일째부터 재고 하한을 위반한다. C는 부족 기간을 브리지 물량으로 채우지만 가정한 가격에서는 B보다 비싸다. 브리지 물량 확보가 항상 최선이라는 결론도 아니다.

기본 조건에서는 A와 B의 도착원가 차이가 3USD/bbl이므로, A의 추가 운임이 3USD/bbl이면 단순 비용이 같아진다. 이를 넘으면 다른 조건이 같다는 가정 아래 비용 순서가 바뀐다. 실제 계약에 이 임계값을 적용할 수 있다는 뜻은 아니다.

## 예제가 보여주는 것과 보여주지 못하는 것

보여주는 것은 같은 기준으로 대안을 비교하고 물리적으로 불가능한 계획을 제외하는 절차다. 회사 손익의 개선, 원유별 실질 경제성, 실제 품질·수율, 계약 변경 가능성, 정상 가동이나 안전을 검증하지 않는다.

현재는 원료를 같은 품질의 단일 물량으로 본다. 샤힌의 원료 선택과 내부 투입 기회비용, 제품별 출하 조건은 별도 설계 단계다. 실제 운영시스템 연동, 최적화 솔버, AI 자동 구매는 없다.
