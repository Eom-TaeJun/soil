# 회사 방향과 수급 업무를 연결한 통합 결론

기준일 2026-10-14. 기존 작업 57a8b7d와 Cowork 361a916을 통합 검토했다. 이 문서는 공개자료에 근거한 직무 해석과 프로젝트 설계이며 회사의 내부 과제·평가표가 아니다.

## 1. 현업 담당자에게 전달할 핵심

**생산계획에 필요한 원료를 언제 얼마나 확보해야 하는지, 가격·일정·재고·거래조건을 같은 기준으로 정리하고 판단이 바뀌는 이유를 설명할 수 있는 지원자.**

공급 안정성만 강조해 무조건 비싼 원료를 먼저 사거나, 가격만 보고 저가안을 고르는 접근을 모두 피한다. 먼저 실행 가능한 후보를 가리고 그 안에서 경제성을 비교한다. 입력과 가정이 바뀌면 이전 결론도 수정한다.

포스코 약 1000자는 실제 현장 이해·판단 기준 수정·사람 간 협업의 근거다. 프로젝트 약 500자는 그 방식을 정유·S-OIL 수급에 맞춰 학습하고 검증한 근거다. 프로젝트를 또 하나의 팀 협업 경험이나 회사 실무성과로 바꾸지 않는다.

## 2. 수급 전체 업무와 이번 계산의 경계

[공식 직무소개](https://www.s-oil.com/company/recruit/Job0102.aspx)는 수급계획의 공장최적화·Feed-stock 구매, 원유수송의 원유선 용선/운영·제품선 용선·통관, 수급운영의 수급·재고·판구매 관리를 명시한다. 2026-10-14 HTML 본문을 재확인했다.

[공식 과거 인터뷰](https://www.s-oil.com/m/company/recruit/Interview.aspx)는 영업 환경과 공장 운전을 함께 고려한 가동량·운전모드의 경제성 판단, 생산과 판매의 의견 조정을 설명한다. 인터뷰의 과거 직책·경력을 현재 조직이나 신입 배치 규칙으로 사용하지 않는다.

업무를 이해하는 순서는 시장·제품 판매조건 → 가능한 생산량·운전조건 → 필요 원료와 구매 대안 → 선적·용선·입고 → 사용 가능 재고 → 계획과 실제의 차이 점검이다. 이는 여러 기능이 정보를 주고받는 관계를 표현한 것이지 수급의 단독 승인권을 뜻하지 않는다.

이번 코드는 생산계획·일별 사용량을 고정하고 발주 전 추가 물량의 공급 메뉴를 비교한다. 실제 정제 가동량, 운전모드, 원유별 수율, 제품별 판매수익·정제마진, 계약 체결을 계산하거나 결정하지 않는다. 수송저유·생산기획·품질·판매의 모든 업무를 수급으로 합치지 않는다.

## 3. 회사 방향에서 선택한 두 질문

### 장기 조달·수송 기반 위에서 무엇을 보완할 것인가

[계약 상대방 Bahri의 2025-10-16 발표](https://www.bahri.sa/en/news-insights/news-insight/2025/bahri-renews-10-year-contract-of-affreightment-with-s-oil-corporation-transport-crude-oil-cargoes/)는 10년 운송계약 갱신과 아라비아만·홍해에서 온산까지의 운송 관계를 설명한다. 이번 실행에서 공식 검색 수록 본문을 확인했다. 운임 고정, 매번 제때 도착, 모든 항로 즉시 이용 가능까지 보장하는 근거는 아니다.

Cowork는 1Q26 IR p11의 장기 원유공급·수송과 다른 공급사·현물 보완 설명을 텍스트로 확인했다고 기록했다. 그 확인 수준을 유지한다. 이번 실행에서는 [공식 IR 목록](https://www.s-oil.com/en/relation/ir/ConferenceCall.aspx)의 1Q26 발표일 2026-05-11, 2Q26 발표일 2026-08-03은 확인했으나 PDF 본문·이미지 재확인은 실패했다. 월별 카고 수를 일별 확정입고로 환산하지 않는다.

프로젝트의 해석: 기존 계약을 자유롭게 바꾸는 문제가 아니라, 주어진 조달 기반에서 아직 계약하지 않은 추가 물량을 어떤 시점·물량·조건으로 확보할지 비교한다. 실제 S-OIL에 현재 원료 부족이 있다는 주장은 아니다.

### 샤힌의 통합 생산과 원료 유연성을 어떻게 이해할 것인가

[공식 블로그](https://story.s-oil.com/)의 2026년 8월 샤힌 관련 검색 수록 요약은 원가 경쟁력·에너지 효율·원료 활용 유연성의 방향을 설명한다. 사용자 제공 링크 기록의 2026-08-18 회사 발표와 Cowork의 2Q26 IR 텍스트 기록을 함께 보존한다. 이번 실행에서 개별 공식 발표 본문과 IR 이미지는 다시 확보하지 못했다.

그 방향의 직무적 의미는 단순 증설량 암기가 아니라 내부 유분과 외부 원료, 기존·신규 공정, 생산과 인수·출하 조건을 연결해 선택의 경제성을 확인하는 데 있다. 이것은 공개 방향에서 도출한 해석이다. 원료 유연성이 곧 아무 원유나 즉시 대체할 수 있다는 의미는 아니다.

83%는 Cowork가 샤힌 원료의 내부 연계 구성으로 읽은 값이다. 회사 전체 원유 자급률·현재 조달 실적·원가 절감률로 바꾸지 않는다. 최종 500자에 이 수치가 필수는 아니다. 이번 구현을 샤힌 원료 최적 배분이나 외부 판매 대 내부 투입의 이익 비교로 부르지 않는다.

## 4. 지정학적 사건을 업무 질문으로 바꾸기

[EIA 2026-10-06 STEO](https://www.eia.gov/outlooks/steo/report/)와 [공식 보도자료](https://www.eia.gov/pressroom/releases/press593.php)의 검색 수록 본문을 재확인했다. 중동 물류 제약과 경유시장 긴축을 설명하지만 회복 경로는 전망이다. 모델 입력 기준은 10월 1일이며 이후 모든 사건이 반영된 실시간 정보가 아니다.

외부 사건 → 영향 가능 항로·공급원 → 해당 견적·선적·도착일 확인 → 원료 사용 가능일과 재고 여유 → 전량 조기·부분 보완 등 후보 → 조건별 비용·제약 비교로 연결한다. 뉴스에서 임의로 '3일 지연', '운임 2달러 상승'을 실측값처럼 추출하지 않는다. 그 숫자는 가상 스트레스 조건이다.

제품가격 상승이 원료 도착을 보장하지 않고, 원유가격 상승만으로 회사 이익 방향을 결정할 수도 없다. 반대로 수송 정상화나 공급 확약이 확인되면 위기 중심 가정을 완화한다. 단기 시황과 샤힌의 중장기 방향을 같은 실적 지표로 합치지 않는다.

## 5. 보여줄 기여와 실제 증거

| 보여줄 기여 | 근거 산출물 | 현업의 어떤 확인을 돕는가 |
|---|---|---|
| 회사·업무의 목적부터 파악 | 공식 업무와 프로젝트 범위 구분 | 단순 재고 집계와 전체 공장최적화를 혼동하지 않음 |
| 데이터를 비교 가능한 조건으로 정리 | 출처·기준일·단위, 가상 견적·입고·품질 상태 | 서로 다른 가격조건·시점을 비교하는 오류 방지 |
| 필요한 시점·물량·추가비용 설명 | C80/C160/B의 조건별 비교 | 전량 조기 확보와 필요한 기간 보완의 차이 |
| 결론을 수정할 조건 제시 | B 소량구매·분할비용·저장한도 반례 | 공급사에 확인할 최소물량과 공급 확약 도출 |
| 협업의 입력을 명확히 요청 | 생산·수송·품질·판매별 확인표 | 누가 가진 어떤 정보가 판단을 바꾸는지 제시 |

공식 직무가 요구하는 해외 거래처 의사소통·외국어 역량을 데이터 역량으로 대체하지 않는다. 자료를 정리하는 것은 상업적 협의와 현장 이해를 돕는 수단이다.

## 6. 통합하면서 채택·수정한 사항

유지: 기존 작업의 직무 전체 설명, 출처/가정 구분, 도착과 사용 가능의 차이, 재고·저장 제약 검사.

추가 채택: Cowork의 발주 전 시점 고정, 기존 계약 보존, 80/160kbbl의 필요 조기물량 비교, 최소 구매량 반례, 결론의 임계조건.

수정: 500자의 중심을 '샤힌과 지정학 이슈를 안다'에서 '그 맥락을 이해하고 실제 조달 판단 질문을 구조화했다'로 옮긴다. 산업 소개는 배경, 조건별 판단과 반례는 본문 증거다.

혼합 금지: 기존 P1의 공개 과거 기준가격과 Cowork의 전부 가상 가격은 서로 다른 실험이다. 총비용 숫자를 두 모델 사이 성과 비교로 쓰지 않는다. 코드가 같은 evaluate 함수를 사용하므로 재실행만으로 독립 알고리즘 검증이라 하지 않는다. 별도 폐쇄형 점검의 한계는 검증 문서에 명시했다.
