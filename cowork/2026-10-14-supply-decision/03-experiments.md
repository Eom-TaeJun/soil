# 가정과 비교 실험

이 문서의 모든 운영·가격 수치는 `SYNTHETIC_NOT_COMPANY_DATA`다. 숫자는 실제 회사 성과를 예측하기 위한 보정값이 아니다. 지정 후보의 조건별 비교가 목적이다.

## 공통 가정

| 변수 | 기준값 | 변화 또는 확인 범위 |
|---|---|---|
| 기간·의사결정 | 7일, 1일차 이전 일괄 결정 | 사후 주문 교체 없음 |
| 기초재고 / 일사용 / 일말 하한 | 240 / 80 / 80kbbl | 첫 단계에서는 고정 |
| 저장 한도 | 600kbbl | 후속 400·450·500·550·600·650 |
| 추가 구매 / 기말재고 | 500 / 180kbbl | 모든 후보 동일. 240+500−7×80=180 |
| 저가 공급 가능일 | 3+d일 | d=0·1·2·3일. 기본 도착=통관=품질확인 |
| 저가 포함원가 | 72+f USD/bbl | f=0~6, 1달러 간격의 추가 비용 |
| B 포함원가·물량 | 72+b USD/bbl, 500kbbl 전량 | b=0~8, 1달러 간격; 기본3. 불가/소량구매 가능을 별도 입력 |
| E 포함원가·물량 | 85 USD/bbl, 3일 사용 가능 | q는80kbbl 단위, 기본 한도160. 후속 한도0·80·160·240 |
| 반례의 B 소량 공급 | 별도80kbbl 단위, 별도한도160 | E 공급한도와 독립. E가 없어도 D를 검토 |
| C의 후속 물량 | 500−q, A와 같은 3+d일 | A와 동일한 f·적합성·품질대기 조건 적용 |
| 분할 고정비 | 0kUSD | 후속0·250·500. 운임 포함값과 중복 합산 금지 |
| 품질·수율·사용 순서 | 같은 가상 원료, 일 시작 입고/해제 후 사용 | 품질대기 및 적합성 미확인 사례 포함 |

정수 일 단위는 하역·검사 시점을 단순화한다. 실제 항만·탱크별 작업 순서, 블렌딩, 일중 최대유량, 운전조정은 구현 범위 밖이다. 최소재고는 가상 운영 기준이며 법정 비축이나 회사 안전기준을 대변하지 않는다.

## 수지와 비용

사용 가능일은 도착·통관·품질확인일의 최댓값이다. 사용 가능 일말재고는 전일 가용재고 + 당일 해제량 − 계획사용량이다. 저장량은 대기물량까지 포함한다. 저장량과 가용재고 각각의 수지, 입고 직후 용량, 기말 가용재고를 검사한다. 음수 계획수지는 불가능성을 표시하며 실제 운전을 계속했다는 뜻이 아니다.

물량 단위 kbbl, 단가 USD/bbl이면 아래 비용 단위는 kUSD다.

- A = 500×(72+f)
- B = 500×(72+b)
- C(q) = q×85 + (500−q)×(72+f) + 분할 고정비
- D(q) = q×(72+b) + (500−q)×(72+f) + 분할 고정비. B 소량 구매가 허용되는 반례에만 포함한다.

비용 단위는 백만 USD. 이 표는 지정 입력의 산술 확인값이며 목표 성과가 아니다. 계산기는 `inputs/scenarios.json`의 같은 조건으로 재현한다.

## 도출할 임계조건

초기 가용여유는 (240−80)/80=2일이다. 3일차 시작까지 추가 입고가 필요하므로 예정3일차 대비 하루 지연부터 A가 하한을 위반한다. 기본 조건에서 d일 늦는 저가물량을 보완하려면 q=80d kbbl가 필요하다. E 상한160은 2일 지연까지 대응한다.

A/B 비용 동률은 f=b다. 단, A와 B가 모두 실행 가능할 때만 유효하다. 기본 b3에서 f3이 경계지만, d가 양수이면 A를 동률 후보에 포함할 수 없다.

C/B 동률의 B 프리미엄은 `b*=f+(q/500)×(13−f)+분할고정비/500`이다. 분할 고정비0·f0이면 q80의 경계는 2.08달러/배럴, q160은 4.16달러/배럴이다. 이 값은 가상 견적 메뉴에만 적용한다.

## 전체 조건 비교와 반증

1차 비교는 d=0~3, f=0~6, b=0~8의 252개 조합이다. 나머지 가정은 기준값을 유지한다. 조건별 후보·비용·위반·최소 가용재고·최고저장량을 확인한다. 격자의 선택 빈도는 발생확률이나 실제 시장 점유율이 아니다.

2차 확장은 대표 사례에서 저장 한도, E 상한, B 공급 가능 여부, 분할 고정비를 하나씩 바꾼다. 이 전체 확장 격자는 아직 실행하지 않았다.

반증조건은 B 소량구매, 품질/수율 차이, 조기공급 확약 부재, 분할 비용, 장기계약 변경 불가 등이다. B가 같은 가격으로 소량 공급하면 d1에서 D80은36.24, d2에서 D160은36.48이 되어 기존 C의 우위가 사라진다. 원료가 동등하지 않거나 실제 견적이 없으면 이 숫자를 실무 추천으로 전환하지 않는다.
