# Cowork 수급 의사결정 프로젝트

작업 구분: 사용자 지정 Cowork 전용 작업. 작성일: 2026-10-14, Asia/Seoul. 검토 기준 커밋: `57a8b7d33d41714dd5bfe8c92a9fb8e0ae62b4b1`.

목적은 **시장·물류 정보를 실제 사용 가능한 재고에 연결하고, 실행 가능한 조달 대안과 판단이 바뀌는 조건을 설명하는 능력**을 검증하는 것이다. 공개자료로 문제의 배경을 확인하고, 회사 내부값이 없는 부분은 합성 조건으로 분리한다.

이 폴더는 현재 대화에서 진행한 Cowork 작업을 구분하기 위한 기록이다. 별도 클라우드 실행이나 다른 제품에서의 실행을 뜻하지 않는다. 제출용 자기소개서나 비공개 팀 경험은 포함하지 않는다.

## 읽는 순서

1. [프로젝트 설계](01-project-design.md): 질문, 의사결정 시점, 비교 대안, 회사·직무와의 연결
2. [공개자료와 가정의 경계](02-data-register.md): 확보 수치, 원문, 용도, 확인 수준
3. [실험과 계산 기준](03-experiments.md): 가정값, 비교 시나리오, 임계값, 반증조건
4. [산출물과 학습 기록](04-delivery-and-learning.md): 결과표와 정보 요청표, 수행 단계
5. [검증 기록](VALIDATION.md): 실제 실행한 범위와 미완료 사항

## 기존 작업과의 관계

기존 [P1 설계](../../docs/08-data-and-decision-design.md)와 [readiness 계산](../../examples/readiness_case.py)의 도착·사용 가능 구분을 유지한다. 이 폴더에서는 조기 물량을 80/160kbbl로 나누고, 발주 전 견적 조건과 공급 한도가 선택을 어떻게 바꾸는지 점검한다. 기존 소스와 문서를 변경하지 않는다.

공개자료는 회사의 문제와 확인할 정보를 정하는 데 사용한다. 아래 수치 비교는 가격까지 전부 `SYNTHETIC_NOT_COMPANY_DATA`이며, 회사 최적안·절감액·실제 구매 가능성을 입증하지 않는다.

## 재현

저장소 루트에서 Python 3.10 이상으로 실행한다. 외부 패키지나 네트워크가 필요하지 않다.

```bash
python cowork/2026-10-14-supply-decision/verify_design.py
python cowork/2026-10-14-supply-decision/verify_design.py --check
```

첫 명령은 후보별 비용·재고·보류 사유를 출력한다. 둘째 명령은 대표 사례와 252개 조건 조합, 공급조건 반례를 검증한다. [합성 입력](inputs/scenarios.json)의 예상값은 산술 회귀검증용이며, 회사 성과 목표가 아니다.
