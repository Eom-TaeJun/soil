# 추가 조달의 경제성과 사용 가능 시점을 비교하는 설계

## 검증할 메시지와 질문

시장 변화를 가격·일정·재고 조건으로 나누고, 실행 가능한 후보와 추가 확인사항을 같은 기준으로 설명한다. 특정 대안의 승리는 목표로 두지 않는다.

질문은 **아직 계약하지 않은 추가 조달 물량에 대해, 저가 일괄 구매·조기 일괄 구매·조기 소량과 후속 물량의 조합 중 어느 안이 일별 원료 사용을 충족하며, 어떤 조건에서 선택이 달라지는가**이다.

공식 직무소개는 원료 구매·공장최적화, 용선·통관, 수급·재고·판구매 관리를 포함한다. 1Q26 IR p11은 장기 원유공급·운송계약과 다른 공급사·현물구매를 통한 보완을 설명한다. 이를 근거로 기본 조달을 유지하면서 추가 선택을 검토하는 문제를 정했다. 실제 S-OIL에 원료 부족이나 특정 구매 문제가 발생했다는 주장은 아니다. 출처와 수치는 [자료 등록부](02-data-register.md)에 있다.

샤힌의 내부 원료 연계는 공정 간 선택을 이해하는 배경이다. 원유별 수율·공정 여력·고객 인수조건을 확보하지 않았으므로 샤힌의 실제 원료 배분 계산으로 확대하지 않는다.

## 의사결정 시점과 범위

- 모든 후보는 1일차 이전에 비교한다. 지연 변수 d는 이때 제시된 공급 가능일 또는 사전 스트레스 조건이다.
- 기존 계약은 취소하지 않는다. 간단한 7일 창에서는 이미 도착한 물량을 기초재고에 포함하고, 창 안의 추가 확정입고는 0으로 가정한다. 실제 회사의 장기계약 입고가 없다는 의미가 아니다.
- 새로 결정할 구매량 500kbbl, 계획 사용량 560kbbl, 기말 사용 가능 재고 180kbbl를 모든 후보에서 맞춘다.
- 후보별로 실제 다른 원유를 가정하지 않는다. 하나의 가상 동등 원료에 대한 공급 메뉴다. 적합성 미확인은 검토 보류한다.
- 발주 후 지연을 알게 된 상황의 대응은 별도 문제다. 이미 선택한 주문을 고정하고 추가발주·취소비·기말재고를 다시 정의해야 한다. 이번 결과를 사후 무료 교체 성과로 읽지 않는다.

## 비교할 공급 메뉴

| 후보 | 새로 구매하는 구성 | 확인하려는 판단 |
|---|---|---|
| A | 저가 공급원에서 500kbbl, 3+d일 사용 가능 | 저가를 유지해도 재고 하한을 충족하는가 |
| B | 조기 공급원에서 500kbbl, 3일 사용 가능 | 전량 조기 확보에 지불할 추가비용은 얼마인가 |
| C80·C160 | 별도 조기 공급원 E에서 q=80 또는 160kbbl를 3일에 확보하고, 나머지는 A 공급원에서 3+d일 확보 | 필요한 만큼만 조기 조달하면 더 나은가 |
| D80·D160 | B도 소량 구매 가능하다고 가정을 바꾼 반례. q를 B 가격으로 3일에, 나머지를 A에서 확보 | C의 우위가 어떤 견적 제한에 의존하는가 |

B는 기본 실험에서 500kbbl 전량 견적만 유효하다고 **가정**한다. 이것은 실제 S-OIL 거래조건이나 시장 관행이 아니다. B의 소량 구매가 가능하면 E의 고가 물량이 불리해질 수 있으므로 D 반례를 반드시 함께 제시한다. E 한도는 기본 160kbbl이며 공급 한도 확대 자체도 가정이다.

## 판단 순서

1. 원료 적합성·견적 유효기간·구매 가능 물량과 계약조건을 확인한다. 자료가 없으면 실제 거래 추천을 보류한다.
2. 도착·통관·품질 확인 중 가장 늦은 날을 사용 가능일로 잡는다. 아직 해제되지 않은 물량도 저장공간은 차지한다.
3. 일별 사용 가능 재고 하한과 입고 직후 저장 한도, 기말재고를 검사한다.
4. 가정상 실행 가능한 후보끼리 총조달비를 비교한다. 동률이면 모두 표시하고, 없으면 없음으로 남긴다.
5. 가격·일정·공급 한도 변화 중 어떤 조건이 결론을 바꾸는지 설명하고 관련 기능에 확인할 정보를 연결한다.

총조달비는 동일 원료·동일 사용량 비교의 비용 지표다. 제품 매출과 공정별 변동비를 계산하지 않으므로 이익이나 정제마진 개선으로 부르지 않는다.
