# 산출물과 학습 기록

## 최종적으로 남길 결과

| 산출물 | 필수 항목 | 무엇을 증명하는가 |
|---|---|---|
| 공개자료 목록 | 원문·시점·단위·관측/전망·사용 한계 | 회사 사실과 가정의 구별 |
| 조건별 대안표 | 후보, 가능/불가/보류, 비용, 첫 위반일 | 가격과 실행 조건을 함께 검토 |
| 일별 수지표 | 입고, 해제, 사용, 가용재고, 대기량, 저장량 | 총량이 맞아도 중간 부족·용량 초과가 생김 |
| 임계조건표 | 최종 필요입고일, 최소 조기물량, 비용 동률 조건 | 언제 판단을 유지·변경해야 하는지 설명 |
| 반례와 정보 요청표 | 가정을 바꾼 결과, 확인할 정보, 관련 기능 | 결론의 한계와 협업에 필요한 정보 |

핵심 결과지표는 가정상 실행 가능 여부, 재고·저장 여유, 실행 가능한 후보의 총조달비다. 실제 주문 단가·납기·적합성 정보가 없으므로 회사 절감액과 최적 구매량은 결과지표로 삼지 않는다.

## 관련 기능에 확인할 정보

| 확인할 정보 | 관련 기능의 예 | 확인 결과가 바꾸는 판단 |
|---|---|---|
| 일별 필요 투입량·정비·원료 적합성 | 생산·생산기획 | 필요한 조기물량, 후보 자격 |
| 도착·하역·통관 가능일 | 구매·수송·통관 | 사용 가능일, 지연 여유 |
| 품질 해제와 대기물량 | 품질·저장 | 가용재고와 탱크 점유 구분 |
| 최소 구매량·분할 견적·공급 확약 | 구매·공급사 | B 전량 가정, C와 D의 비교 |
| 출하·고객 인수 약정 | 판매·출하 | 후속 생산계획을 조정할 수 있는 범위 |

이 표는 정보 요청 설계이며 S-OIL의 실제 부서별 결재체계가 아니다. 실제 부서와 협업한 실적으로 서술하지 않는다.

## 수행과 학습을 연결하는 순서

1. 자료의 기간·단위·가정 여부를 직접 확인한다. Dubai 분기 말 월평균과 분기 전체 평균의 차이를 설명한다.
2. S0~S9의 선택과 제외 이유를 일별 수지에서 추적한다. 계산 결과를 보기 전의 예상과 달랐던 점을 기록한다.
3. B 소량구매 반례를 검토한다. 무엇을 확인하면 기존 결론을 철회할지 설명한다.
4. 입력 하나를 바꾸고 결과를 다시 계산한다. 일수·물량·비용이 함께 바뀌는 이유를 확인한다.
5. 실제 수행 후에만 배운 점을 채택한다. 기존 팀 경험과 이번 개인 탐구는 각각의 실제 수행 범위를 유지한다.

개인 검토 메모 양식은 초기 판단 / 새로 확인한 조건 / 수정된 판단 / 반대 결과 / 추가 질문 / 직접 설명 가능한 근거다. 개인 경험과 강약점 메모는 공개 저장소에 작성하지 않는다. AI가 만든 계산을 사용자가 직접 검토한 범위와 구분한다.

## 현재 완료와 다음 작업

완료 여부와 실행 명령은 [검증 기록](VALIDATION.md)을 따른다. 본 작업은 구체 설계, 합성 시나리오, 계산 일관성 점검까지다. 실제 회사 자료 검증, 공개 시계열 전체 수집, 후속 확장 격자, 사람 간 협업, 업무시간·오류 개선 측정은 아직 수행하지 않았다.

다음 순서는 PDF 도표 이미지 대조, 사용자의 대표 사례·반례 검토, 필요한 추가 자료 선정이다. 새로운 기능은 현재 판단을 설명하는 데 필요한 경우에만 추가한다.
