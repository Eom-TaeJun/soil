# 최근 산업과 S-OIL의 방향을 수급 업무로 연결하기

기준일: 2026-10-14. N번호의 원문·확인 수준은 [추가 출처](../sources/2026-10-14-update.md). 기존 조직·직무 상세는 [02 문서](02-role-and-interfaces.md)를 유지한다.

## 1. 실제로 하는 일과 권한의 경계

공식 수급 직무의 세 범위는 수급계획(공장최적화·Feed-stock 구매), 원유수송(원유선 용선·운영, 제품선 용선, 통관), 수급운영(수급·재고·판구매 관리)이다.[N08] 과거 인터뷰는 영업 환경과 공장 운전의 경제성을 함께 검토하고 생산과 판매 간 의견을 조정하는 업무를 설명한다.[N09]

따라서 이 프로젝트의 직무 해석은 **원료·생산·판매의 물량과 시점을 맞추면서, 제약을 충족하는 대안의 경제성을 설명하는 일**이다. 수송저유·해외영업·생산기획의 모든 업무를 수급의 단독 권한으로 합치지 않는다. 실제 현재 팀 조직도, 신입 배치, 거래·가동 승인권과 내부 KPI는 미확인이다.

| 기능 | 확인할 정보 | 제안하는 신입 기여 | 권한 경계 |
|---|---|---|---|
| 수급계획 | 시장가격 조건, 구매 대안, 공정 적합성 | 전제·단위가 맞는 대안표 | 운전·발주를 독자 승인하지 않음 |
| 원유수송 | 선적, 도착, 하역·통관, 용선 조건 | 지연이 물량수지에 미치는 영향 | 기사만으로 특정 항차를 변경하지 않음 |
| 수급운영 | 사용 가능 재고, 입출고, 판구매 약정 | 기간 총량과 일별 공백을 분리 | 재고·품질 기준을 임의 완화하지 않음 |
| 유관 생산·품질·판매 | 원료 적합성, 생산 범위, 고객 인수 | 추가 확인 질문과 변경 근거 | 아래 정보요청표는 실제 RACI가 아님 |

## 2. 단기 충격과 구조적 변화는 다른 시간축이다

10월 자료의 단기 핵심은 중동 물류 차질과 경유시장 긴축이다. EIA 10월 전망은 공급 회복 경로에도 불확실성이 있음을 전제로 하고, IEA는 10월 7일과 11일 경유 중심 비축물량 방출의 신속한 이행·추가 검토를 제시했다.[N01-N03] 유가 상승, 제품 마진 상승, 원료 도착 지연이 동시에 나타날 수 있으므로 회사 이익의 방향을 한 변수로 확정하지 않는다.

10월 4일 OPEC+ 발표는 11월 필요 생산량의 유지라는 정책이다.[N04] 이는 실측 생산량·선적량·수입 가능 물량과 다르다. 9월 17일 IEA 러시아 정제시설 분석의 3.8백만 b/d는 6월의 처리량이지 9월의 현재 수치가 아니다.[N10]

중기에는 설비·공정 통합과 원료 및 에너지 효율 경쟁을 본다. 정부의 7월 22일 자료는 7월 20일 승인된 여수 사업재편 및 후속 통합·배관 투자 계획을 설명한다.[N07] 승인일, 발표일, 완료일을 구분한다. 단기 경유 호황을 모든 석유화학 제품의 구조적 수익성 개선으로 확대하지 않는다.

## 3. 그 안에서 S-OIL의 위치와 실제 행동

S-OIL은 샤힌을 통해 정유에서 석유화학으로 연결되는 생산기반과 원료 활용 유연성을 강화하는 방향을 발표했다.[N05] 투자·설계상의 경쟁력 주장과 실제 안정 가동·판매 성과는 별개다.

또한 Bahri는 2025년 10월 16일 장기 운송계약의 10년 갱신을 발표했으며 아라비아만·홍해와 온산 사이 운송 관계를 설명했다.[N06] 계약기간·선대 접근은 확인되지만 모든 운임 고정, 항차 무지연, 특정 우회항로의 즉시 사용 가능성을 의미하지 않는다.

이 두 사실을 연결한 **해석**: S-OIL을 단순히 '저렴한 원료를 사는 회사'로 설명하기보다, 장기 조달·수송 관계와 정유·석유화학 통합 선택지를 실제 사용할 수 있도록 연결하는 회사로 이해한다. 하지만 원료 유연성이 언제나 더 높은 수익으로 이어지는 것은 아니다.

| 비교 관점 | 일반적인 외부 원료 의존형 공정의 질문 | 통합형 생산체계에서 추가되는 질문 |
|---|---|---|
| 원료 | 외부 원료를 어떤 조건으로 확보하는가 | 내부 유분 사용의 기회비용·적합성과 대체 원료의 제약은 무엇인가 |
| 물류 | 언제 도착하고 사용할 수 있는가 | 기존 설비와 신규 설비의 투입·저장·출하 일정도 맞는가 |
| 판매 | 제품 순판매가치와 인도 약정은 무엇인가 | 내부 투입과 외부 판매 중 어떤 선택이 현재 가능한가 |

이는 경제적 운영형태 비교이며 특정 경쟁사의 실제 원가·수율 순위를 계산한 표가 아니다. 동종사보다 우월하다고 단정하지 않는다.

## 4. 회사 방향에서 도출한 직무상 확인 과제

원료 유연성 → 투입 가능한 유종·성상·공정 여유 확인 → 같은 산출·품질 기준의 도착원가와 기회비용 비교 → 실제 사용 가능 시점과 고객 인수조건 점검 → 대안 또는 추가 확인 요청.

장기 수송기반 → 확정 선적·항차·도착 일정 확인 → 지연 시 가용재고 소진일 확인 → 조기 대체 물량·분할 구매·운영 조정의 가능 조건 비교. 회사의 실제 검토·승인 체계는 미확인이다.

프로젝트가 보여줄 것은 이 전달경로를 구조화하는 능력이다. 수급 담당자가 신규 설비의 운전, 안전·품질 승인, 판매계약 변경을 모두 결정한다고 가정하지 않는다.

## 5. 유지·수정·기각 조건

- 원료·운송 정상화와 제품 공급 회복이 확인되면 위기 중심의 문장과 스트레스 조건의 비중을 낮춘다.
- 원료 대체가 품질·운전 제약으로 불가능하면 가격 비교 후보에서 제외하거나 검토 보류한다.
- 고객 인수·출하가 생산 확대를 제한하면 높은 제품가격만으로 증산을 정당화하지 않는다.
- 실제 회사 전략이나 직무 설명이 변경되면 기존 프로젝트의 지표·질문부터 바꾼다. 오래된 신년사·인터뷰를 우선하지 않는다.
- 가상 저가안이 납기·재고·적합성을 모두 충족하면 그대로 유지한다. '비싼 안이 더 낫다'는 결론을 만들려고 가정을 조작하지 않는다.

샤힌의 2026-10-14 현재 세부 가동 단계와 최신 실측 성과는 이번 업데이트에서 직접 확인하지 못했다. 과거 조사기록의 목표일을 현재 가동 사실로 바꾸지 않는다.
