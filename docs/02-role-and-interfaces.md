# 수급 직무: 무엇을 하고 누구와 판단을 연결하는가

기준일: 2026-10-14. [출처 등록부](../sources/registry.md) 참조.

## 1. 공식 설명과 프로젝트 해석

공식 직무소개는 수급을 수급계획, 원유수송, 수급운영으로 설명한다. 각각 공장최적화·Feed-stock 구매, 원유선 용선/운영·제품선 용선·통관, 수급·재고·판구매 관리를 포함한다.[R01] 웹페이지의 기능 구분을 현재 실제 팀 조직도나 신입의 순환 배치 순서로 해석하지 않는다.

| 공식 업무 범위 | 프로젝트에서 해석한 판단 질문 | 입사 초기 기여를 보여줄 작업물 |
|---|---|---|
| 공장최적화, 원료 구매 | 시장 조건과 공장 조건을 함께 보았을 때 어떤 대안을 다시 비교해야 하는가 | 전제가 같은 대안 비교표, 원료 적합성·운전조건 확인 목록 |
| 용선·운영, 통관 | 필요한 물량이 필요한 날짜에 실제 사용 가능해지는가 | 선적·도착·통관·사용 가능 시점 구분, 지연 영향표 |
| 수급·재고·판구매 관리 | 생산·입고·판매·출하가 일별로 맞는가 | 일별 수지와 재고 예외, 판매·생산 조정에 필요한 확인사항 |

위 작업물은 신입에게 공식적으로 부여된 권한이 아니라 이 프로젝트가 제안하는 기여 방식이다. 회사의 결재권한, 거래한도, 내부시스템은 확인되지 않았다.

## 2. 선배 인터뷰에서 읽을 수 있는 업무 방식

공식 과거 인터뷰의 수급계획 담당자는 시장의 상업적 조건과 공장 운전 조건을 함께 고려하고, 생산과 판매 사이의 의견을 조정하는 업무를 설명한다.[R02] 숫자를 계산하는 능력뿐 아니라 공정과 시장을 이해하고 상대방에게 경제성을 설명하는 능력이 필요하다는 의미로 읽는다.

인터뷰에 등장하는 이전 생산계획 경험은 그 개인의 당시 경력이다. 모든 수급 신입이 공장에서 일정 기간을 근무한다는 증거가 아니다. 자료에 등장하는 직함 또한 현재 보직으로 쓰지 않는다.

기술직 생산기획 설명은 생산계획과 공정 조정, 경제성 검토와 유관 기능의 협업을 다룬다.[R03] 따라서 수급이 생산 현장의 운전 가능성을 단독 확정하거나 생산기획이 모든 상업 조건을 단독 결정하는 모델을 만들지 않는다.

## 3. 고정된 업무, 회사별 차이, 최근 변화

- 고정된 업무: 원료·제품의 수지, 구매·운송·재고·판매 조건을 일관되게 관리하고 변화가 발생하면 계획을 다시 비교하는 일.[R01, R02]
- S-OIL에 맞춰 볼 차이: 장기 원유 운송 관계, RUC/ODC를 통한 통합 운영의 경험, 샤힌과 연계한 제품 공급경로 준비.[R21, R22, R23] 각 관계의 수치적 이점은 미확인이다.
- 최근 확인한 방향: 안전한 샤힌 완공과 안정적 운영, 내실 운영, 디지털·AI 혁신이라는 회사의 경영 과제.[R47] 이를 수급에서 어떤 시스템과 KPI로 구현하는지는 별도 확인이 필요하다.

## 4. 협업 정보와 승인 경계

아래는 공개 직무 설명을 바탕으로 만든 정보 요청의 가설이다. 실제 S-OIL RACI나 결재 매뉴얼이 아니다.

| 관련 기능 | 비교 전에 받아야 할 정보 | 이 프로젝트가 대신 확정하지 않는 것 |
|---|---|---|
| 생산·생산기획 | 투입 가능 원료, 운전 범위, 정비·시운전 제약 | 실제 가동량 변경 승인 |
| 품질·저장·출하 | 규격, 혼합·탱크 사용 조건, 사용 가능 물량과 시점 | 품질 면제나 안전기준 변경 |
| 판매·마케팅 | 고객별 수요, 인도 약정, 제품 인수 가능 시점 | 판매계약 체결·변경 |
| 구매·수송 | 원료 가격 조건, 도착 일정, 선박·하역·통관 조건 | 실제 용선·발주·거래 승인 |
| 재무 등 지원 기능 | 필요 시 구매대금·환율·자금비용 기준 | 금융거래나 위험 한도 변경 |

사용자는 입력의 불일치와 확인이 필요한 조건을 설명하는 사람으로 제시한다. 각 부서의 권한을 대신 행사하거나 정유공장 운영을 즉시 최적화할 수 있다는 식으로 과장하지 않는다.

## 5. 성과를 어떻게 살펴볼 것인가

회사의 공식 인사평가 KPI는 확보하지 못했다. 다음은 이 작업물의 평가 기준이다.

동일 물량·기말재고·기간을 비교하는지, 입고 전과 후의 재고를 놓치지 않는지, 불가능한 대안을 추천하지 않는지, 판단에 사용한 원문과 가정이 추적되는지, 대안의 순위가 바뀌는 조건을 설명하는지를 본다. 향후 실험을 진행하면 자료 확인 시간과 누락 항목 수를 측정할 수 있지만 현재 개선율을 주장하지 않는다.

## 6. 조직·배치에 대해 남길 미확인

2026년 2월 24일 S-OIL 제공 인사 발표에서 수급부문장 김승후의 승진을 확인할 수 있다.[R45] 이는 공표 시점의 보직이며 이후 변동이나 그 아래 팀별 신입 배치 규칙을 보여주지 않는다. 첨부 조사기록의 분기보고서·채용공고는 후속 확인 대상이다.[R07, R46]

수급 내 어느 팀에 배치되는지, 팀별 인원과 신입 TO, 최종 승인권자, 회의·계획 주기, 실제 사용 시스템과 평가 지표는 이 단계에서 미확인이다. 프로젝트는 기능별 협업을 다루되 조직도를 창작하지 않는다.
