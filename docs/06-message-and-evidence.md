# 평가자에게 전달할 메시지와 500자 설계

확정일: 2026-10-14. 이 문서는 공개용 프로젝트 설계이며 미제출 자기소개서 본문이 아니다.

## 먼저 고정할 것

**시장 변화를 원료의 실제 사용 가능 시점과 공장·판매 조건에 연결해, 실행 가능한 수급 대안을 숫자로 설명하고 협업에 필요한 확인사항을 구조화하는 사람.**

목표는 데이터 분석 도구를 많이 쓰는 사람이 아니라, 무엇을 확인해야 결정할 수 있는지 아는 지원자로 읽히는 것이다. 메시지와 검증 질문은 먼저 정하되 특정 대안의 승리나 절감률을 미리 정하지 않는다. 반대 결과도 그대로 남긴다.

전체 1500자 중 약 1000자는 사용자가 포스코 경험으로 현실을 반영한 판단, 그 근거, 실제 팀 활동을 직접 작성한다. AI는 그 본문을 대신 쓰거나 새로운 강약점·성과를 만들지 않는다. 나머지 약 500자는 같은 판단 방식을 정유산업과 S-OIL 수급에 적용해 본 학습·프로젝트 근거다. 두 개의 무관한 경험을 나열하지 않는다.

## 500자에 남길 증거

| 전달할 신호 | 보여줄 행동 또는 산출물 | 피할 표현 |
|---|---|---|
| 산업 변화를 업무 질문으로 바꿈 | 운송 차질과 제품시장 변화를 도착원가·사용 가능일·재고 제약으로 번역 | 전쟁이면 정유사는 무조건 수혜 |
| 회사별 차이를 이해함 | 샤힌의 원료 유연성이 실제 대안이 되려면 필요한 적합성·운전·출하 정보를 구분 | 샤힌 가동 또는 원료 대체 효과를 이미 검증 |
| 데이터를 판단에 맞게 구조화함 | 출처·기준기간·단위·사실/전망/가정과 화물·일자별 상태를 연결 | 자료를 많이 모았다, AI를 사용했다만 제시 |
| 가격과 실행 가능성을 함께 비교함 | 같은 구매량·사용량·기말재고에서 저가안의 재고 위반 및 대안 변화 확인 | 가상 비용 차이를 회사 절감액으로 제시 |
| 협업을 위한 확인사항을 남김 | 생산에는 원료 적합성, 수송에는 도착 일정, 품질에는 해제 시점, 판매에는 인수조건을 묻는 표 | 실제 현직자·부서와 협업한 것처럼 서술 |

공식 업무와 인터뷰의 근거는 [직무 문서](02-role-and-interfaces.md), 최신 맥락은 [회사·시장 브리프](07-current-company-role.md)에 있다. 위 신호는 공식 채용 채점표가 아니라 공개 업무에 근거해 정한 지원전략이다.

## 분량 배치: 합계 약 500자

- 약 60자: 포스코에서 배운 판단 방식을 다른 산업에도 적용했다는 연결.
- 약 90자: 운송 불확실성과 샤힌의 원료 유연성이라는 산업·회사 맥락. 사건 이름을 나열하지 않는다.
- 약 160자: 회사 공개자료와 시장자료를 확인하고, 가정한 내부 정보를 어떤 항목·관계로 정리했는지.
- 약 120자: 도착 재고와 사용 가능 재고의 차이, 가격상 유리한 안을 다시 검토한 가상 사례의 관찰.
- 약 70자: 서로 다른 조건을 비교 가능한 근거로 정리해 수급 판단을 보조하겠다는 기여.

## 본문과 면접용 배경을 구별

본문 우선순위는 '도착원가, 사용 가능일, 운영상 하한재고, 원료 적합성'이다. 유가 월평균이나 비축유 총량은 검증용 배경에 두고 500자에 모두 넣지 않는다. 최신 시세를 외우는 것보다 해당 지표 때문에 어떤 확인과 비교가 필요해졌는지를 쓴다.

S-OIL 고유 맥락은 샤힌의 원료 유연성과 통합 운영이다. Bahri 장기 운송계약, 석유화학 재편, 비축유 방출, 생산정책은 면접 후속질문을 위한 보조 근거다. 원료 유연성과 해상 수송이라는 두 축을 수급 의사결정으로 연결하되, 샤힌의 실제 공정 최적화까지 수행했다고 쓰지 않는다.

## 완료 상태별 허용 문장

현재 허용: 공개자료 기반으로 회사·직무를 정리했다. 공개 과거 유가 기준과 가상 운영조건을 분리했다. 일별 사용 가능 재고와 도착원가를 비교했다. 조건이 바뀌면 대안 또는 확인사항도 달라짐을 가상 사례로 점검했다.

현재 불가: S-OIL 내부 데이터를 분석했다. 실제 공장 LP를 재현했다. 회사 원가를 절감했다. 샤힌 최적 원료 투입량을 산출했다. 현업 적용 또는 실제 부서 협업을 검증했다. 자료 구조화로 시간을 몇 % 줄였다.

사용자가 코드·자료 채택·반례를 직접 설명할 수 있는지 확인한 다음 제출용 문장을 작성한다. AI가 구현한 것을 사용자가 처음부터 전부 독자 개발한 것처럼 옮기지 않는다.

## 예상 후속질문

1. 왜 유가만 보면 부족한가? 가격의 수준과 제품 순판매가치, 수송·원료 적합성, 사용 가능 시점은 다른 변수다.
2. 회사 내부자료 없이 무엇을 확인했는가? 공개사실과 가정의 구분, 수지·제약의 산술, 조건별 후보 변화까지다. 실제 최적안은 아니다.
3. S-OIL에 왜 필요한가? 공식 수급 업무와 샤힌의 통합·유연성 방향에 연결한 질문이며, 실제 내부 우선순위·시스템은 미확인이다.
4. 포스코와 무엇이 연결되는가? 철강과 정유가 같은 산업이라는 뜻이 아니라, 변수의 의미와 실행 조건을 확인해 판단기준을 조정하는 방식이다.
5. 어떤 결과가 나오면 생각을 바꾸는가? 저가안이 계속 제약을 충족하면 유지한다. 공급 회복·운임 정상화·품질 승인·고객 인수조건 변화 시 다시 비교한다.
